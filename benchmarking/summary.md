# Benchmark query inventory

Catalogue `2026-10-02-v7`. This table covers all 30 scored test queries (Q01-Q30) and all 24 unscored evolution queries: set A (E01-E12, California Current) and set B (E13-E24, Tasman Sea and East Australian Current). The test queries are ten paper verifications and twenty open problems. The evolution queries are all open problems. Exact executable questions are linked in the first column.

The second column lists scientific inputs needed for the question, including type, time, sampling, spatial/depth scope and variable names. The `C_CORE` binding exposes its six existing fields plus grid metadata; a question may use only a subset. CMOMS basin/strait extents come from the actual supplied grid, not an assumed rectangle. Named coastal regions need analyst-defined wet masks. Explicit new diagnostic boxes are request footprints to be checked against that grid.

**Paper verification uses data that cover the paper's own study period.** Each paper row states the paper's period, and `task_info.json` records it under `period_match`. Where a finding still depends on a longer record or on data that are not supplied, the rubric marks it partly testable or not testable.

Seven of the twenty open problems use CMOMS (Q11-Q14, Q16, Q17, Q22). The other thirteen use public data in the Arabian Sea (Q15, Q18-Q21), the Gulf of Mexico (Q23-Q26) and the East China Sea (Q27-Q30).

The two agent-visible diagnostic groups are **requested, not yet available**: `C_PRODUCTION` (`P_Production`, `NO3_uptake`, 116-120 E/16-20 N, 0-100 m) and `C_CARBON` (`CO2_airsea`, `pCO2`, 112-116 E/20-23 N, surface). Both request 2011-2020. The CDL lists interval-averaged rates and native units; it does not establish time coverage or averaging frequency. Daily means are requested, and actual intervals must be documented and used in integration. These groups are owner-staged and never automatically downloaded.

**Brief assessment criteria are a plan, not verified answers.** Test references and tolerances must be computed independently and frozen before formal judging. Paper verification requires a separate verdict for every listed finding: reproduced, partly reproduced, not reproduced, or not testable. Use the supplied data's results rather than copying published numbers. All scored questions require executed, traceable analysis, justified methods and uncertainty; failed/empty attempts score zero.

Q05 and Q11-Q13 use private, independent reference diagnostics computed from the same core fields supplied to each agent. No native heat or oxygen budget archive is required. Unresolved residuals are not measured surface fluxes or biological processes; associations alone do not settle causal attribution.

Evolution rows give qualitative learning-review criteria; they are not scored benchmark rubrics.
