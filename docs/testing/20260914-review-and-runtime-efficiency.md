## 修改

1. **删除 Coordinator 的额外完成协议。** 删除模型工具 `finish_research` 及相应提示。
   DeepAgents 仍负责原生派发和同线程续跑。子代理完成通知同时更新原生 async_tasks 的
   success/error；旧 run 的通知不能把新续跑标记结束。Coordinator 普通回复在有活动任务时
   是进度，无活动任务时即是最终回答。内部 research_complete/final_answer 仅用于前端流
   投影，不由模型填写。自动通知接线仍保留，不另建调度器或语义“完成判定器”。
2. **重试从短等待开始。** 主调用约 2 秒起步，连续失败按 2、4、8…退避到 30 秒并加抖动；
   摘要调用同样缩短初始等待并逐步退避。保留可取消的瞬时故障重试、永久错误传播，以及
   API 失败不计入有效研究调用额度。不改模型，不提高/降低研究轮次额度。
3. **复审不清空模型会话。** 原实现每次 reviewer.ainvoke 只有一条新的 HumanMessage，
   虽然内核保留，模型记忆却丢失。现在把审核者的原生消息、文件/Skill 状态和摘要状态保存在
   Expert 图的 reviewer_state 中，复审和同线程后续审核直接接着工作。作者不接收审核者私有
   会话；Coordinator 仍只收报告、审核文件路径和执行事实。
4. **审核不再继承作者职责提示。** 审核者不附加“自主分析、支持统计、产图”等作者 profile，
   不附加经验捕获提示。审核聚焦代码常见错误、数值与产物一致性、图件问题和明显越界声称；
   允许针对具体疑点的小范围计算，不重新研究。复审关注改动和相关影响。不强制常见错误
   列表变成每项必做测试，不把未检验自动判通过。
5. **减少重复文件内容进入模型。** 在已有 ToolHistoryRepairMiddleware 的有效消息边界，
   同一 read_file/ls/glob/grep 参数返回的相同大段内容只保留一个完整副本，后续副本引用
   仍可见的工具结果。原始 checkpoint 不删。工具仍真正执行，确保文件改变、分页、权限
   失败不会被缓存掩盖；摘要后若原文不再可见，新读取完整保留。执行和写入不做去重。
   这减少重复输入，不声称直接消除所有模型往返。摘要明确保留已知文件事实、已完成检查
   及可复用内核变量，避免把已做事项又总结成待办。

   命名 oceanx；显式 OCEAN_SANDBOX_PYTHON、OCEAN_CONDA_ENV 和非 base 激活环境仍保留。
