# Campeche 三组实验比较（2026-09-10）

## 结论先行

本轮没有证明 Tree 提高了最终科学可靠性。无 Tree 的最终答案在“不把单年相关性当作因果”方面最克制；Tree 的独立复核确实发现了数值问题，但最终仍把分层机制升级为 Established；Claude 探索范围最广，却存在可复现的代码错误和严重叠图问题。三组都抓住了相同的表层季节变化，但没有一组足以完成严格的形成/维持机制因果归因。

这是一次同题单次案例，不是统计意义上的排名，也没有使用未经验证的数字评分。核查为关键代码与证据抽查，不是逐行形式验证；未重跑完整科学分析。

## OceanX+Tree：复核有用，但树的终态不是科学证明

1. 实际热预算计算在不可变执行 `codeexec_27fe460eac1742bca0f2470d5eed40d4/code/analysis.py`：`adv=-(Ub*Tx+Vb*Ty)`；`tend=np.gradient(Tb,86400,axis=0)`，此次没有之前讨论过的秒/天换算错误。
2. `aw_series` 对缺测值使用 nansum，但分母仍为固定海洋面积。tendency 与 adv/residual 的有效格点不同，结果出现 **51 − 3.4 − 40.6 ≈ 7 W/m²** 的闭合差。独立复核和最终报告已经承认这个问题，但没有修正原始诊断。最终图中显示的是未修正的诊断。
3. 分层、浅混合层及低叶绿素与变暖一致，并不直接测量垂向混合被抑制的热量贡献；没有净热通量、垂向速度/混合项，不能把这一解释定为“Established / 已确立”。表面加热与分层不是互斥候选。
4. 树数据库有12个节点（含根）和7个测试条目，确实出现多层分解；但表面通量/短波/潜热/夹卷等细分多数停在“数据无法验证”。更深的树没有增加新的可区分证据，不能作为 Tree 更优的依据。
5. “Horizontal advection refuted”应收窄为“该域、该层、该平均期的已算水平平流项不是主导加热项”，不能推广为环流/涡旋对形成维持完全无作用。

## OceanX w/o Tree：结论边界较好，定量占比仍是近似

1. 最终答案明确写了 descriptive、不是因果归因、一年无法判断异常的气候显著性，以及物理复核未完成。这是本轮最好的证据边界表达。
2. 水平平流代码同样使用梯度形式，积分为热量变化项。最终约14.4 W/m²、约25%的解释涉及约110 m层，而 Tree 使用0–50 m，Claude使用0–100 m且是边界通量形式；这些值不能直接相互判对错。
3. `codeexec_d17c56aebeca40f0afd98ca4282daa4d/code/analysis.py` 的层厚权重按中心深度构建，未精确截断110 m底界；nansum 对梯度缺测格点相当于无贡献，而热储量可用格点不同。百分比只能作为待一致掩膜和垂向边界核查的近似值，不是精确闭合预算。
4. 低区域平均涡度、弱平均EKE不能独自排除持续环流或局地暖涡。报告“没有持续涡旋/回流”的表述过强。它并没有完成事件级涡识别验证。
5. 最终稿仍有“残差归因于表面热通量和再分层”的句子，与后文谨慎限定有张力。正确版本应明确残差还包括未计算的垂向输运、混合、扩散及数值误差。

## Claude：发现两个可复现代码错误，图件也不能直接使用

### 1. 混合层深度缺测处理错误

`code/helpers.py:first_crossing` 中：

```python
last_valid = nz - 1 - (~valid)[..., ::-1].argmax(axis=-1)
```

这里搜索了“反转后的无效层”，不是最后有效层。用原函数作小型诊断：深度 `[0,10,20,30,40]`，剖面 `[1,1,1,NaN,NaN]`，阈值2从未达到，正确的最后有效深度是20 m，原函数返回40 m。对有深层缺测的海洋剖面会返回过深值。

因此最终“冬季MLD 350–450 m、确认深夹卷”的关键结论不可信；具体修正到多少米需要重新计算，不能在这次审计中猜测。

### 2. 连续性垂向速度符号错误

`code/stage2_budget.py:w_from_continuity` 使用：

```python
du = (u.shift(lon=1) - u.shift(lon=-1)) / (2*dxb)
dv = (v.shift(lat=1) - v.shift(lat=-1)) / (2*dyb)
w = -np.cumsum(divv*dz, axis=1)
```

在递增经纬度坐标上，两项差分都是正常空间导数的相反数。原函数在构造的东向发散流场上，给出正的“向下为正”w；连续性要求负值（上升）。由该w得到的上升/下沉季节判定和预算分项需要重算。另外，代码用区域平均w乘区域平均T，而不是区域平均wT，遗漏协方差项。

### 3. 明确的方位与推断问题

报告说异常从94.5°W到91.5°W“向西传播”，但这是向东。由此联想到具体 LCE 机制的事件归因缺乏可靠支撑。表面通量未测量，残差不能直接支持“冬季局地失热最弱”等断言。

### 4. 图件严重重叠

直接打开 `fig04_heat_budget.png` 与 `fig08_mld_blt.png`，均有多个图的标题、坐标轴和色标叠加。代码 `make_figures.py` 在第一幅图 `plt.close(fig)` 后继续向同一个 `fig` 对象增加新子图；关闭 pyplot 管理并不会清空该对象。9个文件存在不等于9张可用图。

Claude 的交付结构最完整，但科学代码及这些图件不合格。没有替 Claude 修代码/重画，以保留原始基线结果。

## 最终判断

- 作为初步描述性研究结果：无Tree版本的最终措辞最适合继续人工审查，但不是已验证的科学定论。
- Tree有实际复核和更深分解，却没有在本例转化成更可靠的主结论；不能宣称Tree胜出。
- Claude覆盖面广，但本轮有实质算法错误、方位错误及可视化交付错误，不能直接采用其机制结论。
- 应保留的共同结论是夏末表层增暖及其与浅混合层/强分层的同现；对通量、混合和涡过程的贡献排序仍需更一致的预算与可区分证据。
